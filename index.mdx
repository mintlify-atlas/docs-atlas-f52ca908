Athas is a lightweight desktop code editor built for developers who want speed without sacrificing features. Built with Tauri (Rust + React), it runs natively on macOS, Linux, and Windows while keeping a small footprint. From AI-powered coding assistants to full Git integration and LSP-backed code intelligence, Athas covers your entire development workflow in one editor.
