Athas ships with a full set of built-in keyboard shortcuts and lets you switch to a preset that matches the editor you are most comfortable with. Presets remap the default shortcuts to mirror those of popular editors without changing any behavior — the same commands run, just under different keys.

## Default shortcuts

The following shortcuts are active when no preset is selected (`keybindingPreset: "none"`).

### File operations

| Key | Command |
|---|---|
| `cmd+s` | Save file |
| `cmd+shift+s` | Save file as |
| `cmd+w` | Close file |
| `cmd+shift+t` | Reopen closed file |
| `cmd+o` | Open file |
| `cmd+p` | Quick open (`file.quickOpen`) |

### Edit operations

| Key | Command |
|---|---|
| `cmd+z` | Undo |
| `cmd+shift+z` / `cmd+y` | Redo |
| `cmd+c` | Copy |
| `cmd+x` | Cut |
| `cmd+v` | Paste |
| `cmd+d` | Duplicate line |
| `cmd+shift+k` | Delete line |
| `cmd+/` | Toggle comment |
| `alt+up` / `alt+down` | Move line up/down |
| `alt+shift+up` / `alt+shift+down` | Copy line up/down |
| `shift+alt+f` | Format document |
| `cmd+i` | Inline AI edit |

### Navigation

| Key | Command |
|---|---|
| `cmd+shift+p` | Command palette |
| `cmd+g` | Go to line |
| `F12` | Go to definition |
| `shift+F12` | Go to references |
| `cmd+alt+right` / `cmd+alt+left` | Next/previous tab |
| `ctrl+-` / `ctrl+shift+-` | Navigate back/forward |

### View

| Key | Command |
|---|---|
| `cmd+b` | Toggle sidebar |
| `cmd+j` | Toggle terminal |
| `cmd+shift+f` | Global search |
| `cmd+shift+e` | Show file explorer |
| `cmd+shift+g` | Show source control |
| `cmd+r` | Toggle AI chat |
| `cmd+k cmd+t` | Open theme selector |
| `cmd+k cmd+s` | Open keyboard shortcuts |

## Custom keybindings

In addition to presets, you can override individual shortcuts through the keyboard shortcuts editor. Open it with `cmd+k cmd+s` or via **Settings → Keyboard → Open Keyboard Shortcuts**.

Each binding targets a command ID (for example, `workbench.commandPalette` or `file.quickOpen`) and an optional `when` condition (such as `editorFocus` or `terminalFocus`) that restricts when the shortcut is active.

<Tip>
Preset overrides are applied on top of any custom bindings. If you define a custom binding for the same command, your custom binding takes priority over the preset.
</Tip>

## Key syntax

Athas uses VS Code-style key syntax, automatically normalized per platform:

- `cmd` resolves to `Cmd` on macOS and `Ctrl` on Windows/Linux.
- Chord shortcuts (two-key sequences) are written with a space: `cmd+k cmd+t`.
- Modifier order: `ctrl+alt+shift+cmd+key`.
