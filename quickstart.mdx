---
title: "Quickstart: Open a Project and Start Coding in Athas"
description: "Open your first project in Athas, learn the editor layout, set up an AI provider, and make your first AI-assisted edit — all in under ten minutes."
---

This guide walks you through opening a project, navigating the Athas interface, and getting to a working state with AI chat enabled. By the end you will have a project open, know how to use the command palette, and have a connected AI provider ready to use.

<Steps>
  <Step title="Open a project folder">
    Launch Athas and open your project using one of these methods:

    - Press `Cmd+O` (macOS) or `Ctrl+O` (Windows / Linux) to open the folder picker.
    - Use the menu bar: **File → Open Folder**.

    Once a folder is open, the **file explorer** appears in the left sidebar showing your project's directory tree. Click any file to open it in the editor.

    <Tip>
      Athas remembers your recently opened folders. Reopen them quickly from the welcome screen or via **File → Open Recent**.
    </Tip>
  </Step>

  <Step title="Learn the layout">
    Athas uses a standard editor layout with a few key areas:

    **Sidebar** — The left panel contains four activity tabs, accessible via the icons on the sidebar rail or these shortcuts:

    | Tab | Shortcut |
    |-----|----------|
    | File explorer | `Cmd+Shift+E` |
    | Global search | `Cmd+Shift+F` |
    | Git | `Cmd+Shift+G` |
    | GitHub pull requests | — |

    Toggle the sidebar on and off with `Cmd+B`.

    **Editor panes** — Files open in the main editor area as tabs. Split the editor horizontally or vertically to view multiple files at once. Navigate between tabs with `Cmd+Alt+Right` and `Cmd+Alt+Left`, or switch to a specific tab with `Cmd+1` through `Cmd+9`.

    **Terminal** — Press `Cmd+J` to toggle the integrated terminal. The terminal supports multiple shell profiles and runs in the same window as your editor.

    **Status bar** — The footer shows the current Git branch, active diagnostics, and AI chat controls on the right side.
  </Step>

  <Step title="Use the command palette">
    The command palette gives you keyboard access to every Athas command without touching the mouse.

    Press `Cmd+Shift+P` (macOS) or `Ctrl+Shift+P` (Windows / Linux) to open it. Type any part of a command name to filter the list, then press `Enter` to run it.

    Common commands to try:

    - `Toggle Sidebar` — show or hide the file explorer
    - `Open Keyboard Shortcuts` — view and edit all keybindings
    - `Toggle Theme` — switch your color theme
    - `Format Document` — run the configured formatter on the current file

    Press `Cmd+P` to open **Quick Open**, which lets you jump to any file in the project by name.
  </Step>

  <Step title="Set up an AI provider">
    Athas includes AI chat and autocomplete. To use them, configure an AI provider with your API key.

    1. Open **Settings** from the command palette (`Cmd+Shift+P → Open Settings`) or via the menu bar.
    2. Navigate to the **AI** section.
    3. Choose a provider from the dropdown. Athas supports:
       - **Anthropic** (Claude Sonnet 4.6 is the default model)
       - **OpenAI**
       - **Google Gemini**
       - **xAI Grok**
       - **DeepSeek**
       - **Mistral AI**
       - **Qwen**
       - **OpenRouter**
       - **Ollama** (local, no API key required)
    4. Enter your API key for the selected provider.
    5. Optionally, choose a specific model from the model dropdown.

    <Note>
      Ollama lets you run models locally without an API key. Make sure Ollama is running at `http://localhost:11434` before selecting it in Athas.
    </Note>
  </Step>

  <Step title="Start an AI chat session">
    With a provider configured, open the AI chat panel:

    - Press `Cmd+R` to toggle the AI chat panel.
    - Or click the **AI chat** icon in the bottom-right status bar.

    Type a question or paste code into the chat input and press `Enter`. The AI responds inline in the panel. You can ask questions about your code, request edits, or use it to generate boilerplate.

    To use **AI agents** (such as Claude Code, Codex CLI, or Gemini CLI), press `Cmd+Shift+Space` to open the agent launcher. Agents must be installed separately and are detected automatically once their binary is available.
  </Step>

  <Step title="Explore the Git panel">
    If your project folder is a Git repository, the Git panel gives you a full workflow without leaving Athas.

    Open it with `Cmd+Shift+G`. The panel has three tabs:

    - **Changes** — staged and unstaged file changes with inline diff view. Click a file to see the diff; stage individual files or hunks.
    - **History** — commit log for the current branch.
    - **Worktrees** — manage Git worktrees if you work across multiple branches simultaneously.

    Inline Git blame appears in the editor gutter when **Enable Inline Git Blame** is active in settings. The status bar footer shows your current branch at all times.
  </Step>
</Steps>
