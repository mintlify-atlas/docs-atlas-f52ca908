Athas is a desktop code editor built for developers who want a native application without the weight of an Electron shell. By combining a Rust backend via Tauri with a React frontend, Athas runs natively on macOS, Linux, and Windows. The editor brings together what most workflows actually need — AI coding assistants, Git integration, language server support, Vim keybindings, an integrated terminal, and a SQLite viewer — without requiring extensions for the core loop.

## Supported platforms

Athas runs natively on:

- **macOS** — Apple Silicon and Intel
- **Linux** — x86_64
- **Windows** — x86_64

Download the latest release from the [GitHub releases page](https://github.com/athasdev/athas/releases).

## Additional features

Beyond the core editing loop, Athas includes:

- **Syntax highlighting** via Tree-sitter, with grammar support for dozens of languages
- **SQLite viewer** for browsing local databases without a separate tool
- **External editor support** — open files in your preferred editor from within Athas
- **GitHub integration** — view pull requests, issues, and Actions from the sidebar
- **Enterprise policy controls** — managed mode and an extension allowlist for organizations
