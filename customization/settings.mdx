Athas exposes a broad set of preferences that control how the editor looks, behaves, and integrates with external tools. All settings are persisted per user and take effect immediately without restarting the editor. Open Settings with `cmd+,` (macOS) or `ctrl+,` (Windows/Linux), or via the application menu.

## General

| Setting | Default | Description |
|---|---|---|
| `autoSave` | `false` | Automatically save files after each change |
| `sidebarPosition` | `"left"` | Position of the primary sidebar — `"left"` or `"right"` |
| `quickOpenPreview` | `true` | Preview files in the editor as you navigate the quick open list |

## Editor

| Setting | Default | Description |
|---|---|---|
| `fontFamily` | system mono | Font family used in the code editor |
| `fontSize` | system default | Font size (in px) for editor text |
| `tabSize` | `2` | Number of spaces per indentation level |
| `wordWrap` | `false` | Wrap long lines at the editor boundary |
| `lineNumbers` | `true` | Show line numbers in the gutter |
| `showMinimap` | `false` | Show the minimap scrollbar on the right side |

## Terminal

| Setting | Default | Description |
|---|---|---|
| `terminalFontFamily` | system mono | Font family used in the integrated terminal |
| `terminalFontSize` | system default | Font size (in px) for terminal text |
| `terminalLineHeight` | `1.2` | Line height multiplier for terminal output |
| `terminalLetterSpacing` | `0` | Extra letter spacing (in px) in the terminal |
| `terminalScrollback` | `10000` | Number of lines retained in the terminal scroll buffer |
| `terminalCursorStyle` | `"block"` | Terminal cursor shape — `"block"`, `"underline"`, or `"bar"` |
| `terminalCursorBlink` | `true` | Animate the terminal cursor |
| `terminalCursorWidth` | `2` | Width (in px) of the bar cursor style |
| `terminalDefaultShellId` | `""` | ID of the default shell to open in new terminal sessions |
| `terminalDefaultProfileId` | `""` | ID of the default terminal profile |

## UI

| Setting | Default | Description |
|---|---|---|
| `uiFontFamily` | system UI | Font family for all editor chrome (sidebar, tabs, status bar) |
| `uiFontSize` | system default | Font size (in px) for editor chrome |

## External editor

Athas can hand off the current file to an external terminal editor. Set `externalEditor` to one of the supported values:

| Value | Editor |
|---|---|
| `"none"` | Disabled (default) |
| `"nvim"` | Neovim |
| `"helix"` | Helix |
| `"vim"` | Vim |
| `"nano"` | Nano |
| `"emacs"` | Emacs |
| `"custom"` | Command defined in `customEditorCommand` |

When `"custom"` is selected, set `customEditorCommand` to the full shell command that should open the file (for example, `micro`).

## Core features

The `coreFeatures` object lets you disable individual Athas subsystems. All features are enabled by default.

| Feature key | Default | Description |
|---|---|---|
| `git` | `true` | Git integration (status, diff, staging, commit) |
| `github` | `true` | GitHub pull requests, issues, and Actions |
| `remote` | `true` | Remote workspace and SSH support |
| `terminal` | `true` | Integrated terminal |
| `search` | `true` | Global and project-wide search |
| `diagnostics` | `true` | Error and warning diagnostics panel |
| `aiChat` | `true` | AI chat panel |
| `breadcrumbs` | `true` | File path breadcrumb bar in the editor |
| `persistentCommands` | `true` | Persistent command history |

<Warning>
Disabling a core feature hides its associated UI and panel but does not unload the underlying extension code. Re-enable the feature and restart the editor to fully restore it.
</Warning>
